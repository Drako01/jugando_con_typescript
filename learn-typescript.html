Módulo 01 · Modelo mental

TypeScript no es “JavaScript con tipos” solamente

TypeScript agrega un sistema de análisis estático sobre JavaScript. Te ayuda a detectar inconsistencias antes de ejecutar el programa y a expresar contratos que herramientas, editores y otras personas pueden comprender.

Compile time

El chequeo de tipos ocurre antes de ejecutar el código.

Runtime

En el navegador termina ejecutándose JavaScript; los tipos desaparecen.

primer contrato
const saludar = (nombre: string): string => {
  return `Hola, ${nombre}`;
};

saludar("Alejandro");
// saludar(42); // TypeScript lo rechaza

Módulo 02 · Tipos

Primitivos, unions e interfaces

No se trata de anotar todo. Dejá que TypeScript infiera cuando puede y escribí tipos explícitos en fronteras importantes: funciones públicas, modelos, datos externos y estados compartidos.

modelo.ts
type EstadoCurso = "borrador" | "publicado";

interface Curso {
  id: string;
  nombre: string;
  horas: number;
  estado: EstadoCurso;
  tags?: string[];
}

const curso: Curso = {
  id: "ts-101",
  nombre: "TypeScript Profesional",
  horas: 20,
  estado: "publicado"
};
type

Muy flexible para unions, aliases y composiciones.

interface

Excelente para describir la forma de objetos y contratos extensibles.

Módulo 03 · Funciones y objetos

Entradas claras, salidas previsibles

Una firma de función bien diseñada funciona como documentación ejecutable. Evitá any cuando el dominio puede expresarse de forma segura.

funciones.ts
interface Alumno {
  id: string;
  nombre: string;
  cursoIds: string[];
}

function inscribir(alumno: Alumno, cursoId: string): Alumno {
  if (alumno.cursoIds.includes(cursoId)) return alumno;

  return {
    ...alumno,
    cursoIds: [...alumno.cursoIds, cursoId]
  };
}

Módulo 04 · Narrowing

Reducir tipos antes de usar datos

Cuando un valor puede tener varias formas, TypeScript necesita evidencia para saber cuál tenés en cada rama. Eso es narrowing.

union discriminada
type Resultado =
  | { ok: true; data: string[] }
  | { ok: false; error: string };

function mostrar(resultado: Resultado) {
  if (resultado.ok) {
    console.log(resultado.data.join(", "));
    return;
  }

  console.error(resultado.error);
}
typeof

Útil para primitivos.

in

Comprueba si una propiedad existe.

discriminated unions

Una propiedad común permite modelar estados excluyentes.

type guards

Funciones propias que refinan tipos complejos.

Módulo 05 · Tipos avanzados

Genéricos y Utility Types

Los genéricos permiten conservar información de tipos al escribir lógica reutilizable. Los Utility Types transforman contratos existentes sin copiarlos.

generics.ts
function primero<T>(items: T[]): T | undefined {
  return items[0];
}

interface Profesor {
  id: string;
  nombre: string;
  email: string;
}

type AltaProfesor = Omit<Profesor, "id">;
type EdicionProfesor = Partial<AltaProfesor>;

Módulo 06 · Browser APIs

DOM, módulos y datos reales

Este repositorio usa TypeScript directamente sobre APIs del navegador. El tipado ayuda especialmente al trabajar con elementos que pueden no existir y con valores de formularios que llegan como strings.

dom.ts
const form = document.querySelector<HTMLFormElement>("#cursoForm");
const input = document.querySelector<HTMLInputElement>("#nombreCurso");

form?.addEventListener("submit", (event) => {
  event.preventDefault();

  const nombre = input?.value.trim();
  if (!nombre) return;

  console.log({ nombre });
});
Optional chaining

form?. evita asumir que el nodo existe.

Generics del DOM

querySelector<HTMLInputElement> hace disponible value con su tipo correcto.

Módulo 07 · Arquitectura

De archivo suelto a aplicación mantenible

Separá dominio, persistencia y UI. Los modelos no deberían conocer el DOM; la persistencia no debería decidir cómo se renderiza una tabla. Esa división mejora testabilidad y reduce cambios colaterales.

estructura conceptual
type/
├── models/       # entidades y contratos
├── functions/    # lógica reutilizable
└── index.ts      # orquestación del DOM

assets/js/        # salida compilada
docs/             # teoría complementaria
